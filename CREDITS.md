# Credits

## Court card artwork (J, Q, K)

The kings, queens and jacks are by **Adrian Kennard** (<https://www.me.uk/cards/>), who dedicated them to the
public domain under **CC0 1.0 Universal**. That means anyone may copy, change and use them for any purpose,
with no permission needed. The copies here come from the npm package
[`react-free-playing-cards`](https://www.npmjs.com/package/react-free-playing-cards) version 0.4.2
(its 2-colour set), which redistributes them under CC0.

### Changes made for the Dragon Deck

- Each of the 12 cards has one added layer: a small heraldic dragon perched beside the figure, drawn in the
  set's own colours (gold `#FC4`, red, blue `#44F`) and line weights. Like the rest of each picture, it is
  drawn once and repeated upside down for the bottom half.
- Only the framed picture is used; the corner indices are the Dragon Deck's own.

## Everything else

The number cards, aces, dragon card back, 3D table and code were written for this project.
